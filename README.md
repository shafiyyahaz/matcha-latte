# Matcha Latte 🍵

A cute, aesthetic matcha drink shop website made with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive modern storefront
- 6 unique matcha drink products
- Search and category filters
- Shopping cart with quantity controls
- LocalStorage cart persistence
- WhatsApp ordering
- Indonesian / English toggle
- Dark mode
- Newsletter interaction
- Floating WhatsApp button
- Custom Matcha Latte favicon
